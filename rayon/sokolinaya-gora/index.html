Район Соколиная гора

Соколиная гора — район ВАО Москвы, 93 960 жителей. Метр жилья на вторичке около 403 тыс. ₽ (78-е место из 125 по цене). Экология 7,7 из 10, 92-е место по чистоте. До центра около 28 минут.

Название по месту, где, по преданию, держали царских соколов. В XIX–XX веках здесь выросли заводы, район стал промышленным. Сейчас часть промзон у улицы Буракова застраивается жильём.
