Район Силино

Силино — район ЗелАО Москвы, 41 971 жителей. Метр жилья на вторичке около 304 тыс. ₽ (123-е место из 125 по цене). Экология 2,4 из 10, 1-е место по чистоте. До центра около 98 минут.

Назван по деревне Силино. Застраивался в 1970–80-е, один из самых зелёных районов Зеленограда.
