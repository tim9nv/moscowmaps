# Пилот четырёх страниц — 14 ноября 2026

Пилот ограничен `rayon/otradnoe/`, `rayon/aeroport/`, `parks/park-otradnoe/` и `parks/petrovskiy-park/`.

После обычной цепочки сборки, включая `seo_fix.py`, выполнить:

```sh
python tools/stage1_districts.py
python tools/stage1_parks.py
```

Это целевые постпроцессоры: они сохраняют оформление уже собранных страниц. Сгенерированные HTML вручную не редактировать. Не запускать массовую пересборку только ради пилота: у неё есть известные побочные изменения меню и рейтингов (см. AGENTS.md).

Числа и формулы рейтинга пилот не меняет. Неизвестное значение не является доказанным отсутствием объекта. Источники картографических данных и редакционные источники имеют собственные даты; запуск сборки не обновляет дату проверки фактов.

У парков сведения о входах и проходах публикуются только при наличии подтверждения. Отсутствие подтверждения обозначается явно; точка центра парка не выдаётся за вход. Пилот не требует геолокации и нового API маршрутизации.

Реклама остаётся снятой до одобрения площадки РСЯ. `tools/ads.py` без `--remove` в рамках этого пилота не запускать.

Проверка перед публикацией: повторный запуск целевых скриптов не меняет результат; HTML вне пилота остаётся прежним; числа рейтинга совпадают с основной версией; четыре страницы проверены на компьютере и телефоне; карта, поиск, фильтры, список и popup проверены; выявленные ограничения перечислены в отчёте.
