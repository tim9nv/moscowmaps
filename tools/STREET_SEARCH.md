# Поиск улиц на главной

Поле «Найти район или улицу» с подключением модуля в `index.html`. Подсказки и
клавиатура — `assets/street-search.js`, оформление — `assets/street-search.css`.
Индекс загружается после начала ввода; введённые названия не отправляются API.
Ссылки ведут на существующие `rayon/<slug>/`. У неоднозначного названия нужно
выбрать район; Enter не выбирает произвольный район.

## Обновление данных

Источник: [выгрузка Москвы OpenStreetMap](https://download.openstreetmap.fr/extracts/russia/central_federal_district/moscow.osm.pbf).
Дата исходной выгрузки хранится в `date`, дата сборки — в `built`, метод — в `method`.
Границы и названия 125 районов берутся из `tools/data/districts*.json`.

```sh
python3 -m pip install osmium 'shapely>=2'
curl -L --fail -o /tmp/moscow.osm.pbf https://download.openstreetmap.fr/extracts/russia/central_federal_district/moscow.osm.pbf
python3 tools/build_street_index.py /tmp/moscow.osm.pbf
node tools/test_street_search.mjs
```

`assets/streets.json`: `districts` — `[slug, название, округ]`, `streets` —
`[название улицы, номера районов в districts, альтернативные названия]`.
Названия с переставленным типом улицы объединяются; адресный мусор со слешем
не попадает в индекс. Для каждой улицы приоритет у адресных точек и зданий.
Если адресов нет, используются пересечения линии с районами длиной от 20 м.
Для магистралей motorway/trunk учитываются также пересечения, поскольку на
них мало адресов. Именованные километры МКАД также объединяются в общий
результат «МКАД», сохраняя отдельные записи для уточнения километра. Это поиск по данным OSM, не официальный адресный реестр;
список районов может быть неполным, точный район дома не определяется.
Новая Москва не включена: у неё нет районных страниц в этом атласе.

После изменения JS/CSS или индекса обновить версии в `street-search.js` и его подключении в `index.html`. Не пересобирать все страницы
районов ради поиска. Перед публикацией проверить телефон 390 px, компьютер
1000 px, Enter/стрелки/Escape, пустой запрос, отсутствие результата и переход
на страницу района. `node tools/test_street_search.mjs` проверяет нормализацию,
точные совпадения, варианты названий, неоднозначность и все ссылки индекса.
